Search for indicators, datasets and pages.

## Variants
- **Compact** (36px, `surface-sunken`): sidebar and header; shows the Ctrl K hint and opens the command palette.
- **Large** (52px, `surface`): top of the catalogue page.

## Rules
The whole field is the `label`; it shows the focus ring through `label:focus-within` (the input itself has no outline). Placeholder gives a real example. `aria-label` names what is searched.
