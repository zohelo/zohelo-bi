Słupki rankingowe: porządek i wielkość dla wielu kategorii o długich nazwach.

Group: Wielkość i ranking. Example: "Mazowieckie daleko przed resztą" (PKB na mieszkańca, Polska = 100, 2023, 8 z 16 województw).

## When to use
Porządek i wielkość dla wielu kategorii o długich nazwach.

## Avoid
Kolejność alfabetyczna; kolor każdego słupka inny.

## Colour and marks
Selected item `series-1`, rest `series-context`; reference line `series-reference` dashed; values in a right-aligned column.

## Always
Title states the finding; subtitle states measure, unit, frequency and range; `role="img"` with a one-sentence `aria-label`; Wykres | Tabela toggle; source line; phone variant drawn for 340px with 11px text. Draw with `kit/zchart.js` as the visual reference; production charts come from `packages/visuals`.
