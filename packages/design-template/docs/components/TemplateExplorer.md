Explorer page type: one query bar above the chart, the chart card at full width.

## Rules
Page header: title, a one-sentence lead, "Zapisz widok" and "Pobierz CSV" (primary). Below it one calm query bar (a single row that wraps; a horizontal scroller on phones) of filter buttons in the catalogue's `zt-filter` style: label, current value, a count badge from two items, chevron. Order: Wskaźniki, Obszar, one button per shared dimension (Płeć, Wiek…), Okres, Wykres; then "Wyczyść" only when the query differs from the default, and "Zapisane widoki (n)" at the end. Each button opens a popover (dialog: focus moves in, Esc or an outside click closes, focus returns to the button); on phones the popover is a bottom sheet (full width, at most 80vh, scrolling). The buttons show the state, so there is no separate bar of applied chips; a live region repeats the result for screen readers. Chart card: generated title and subtitle, the chart, legend, notes, source line; its menu holds only "Kopiuj link" and the indicator page. The URL stores the whole view.
