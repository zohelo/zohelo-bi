Catalogue page type in the app shell: search, filter chips, dense indicator rows.

## Rules
Large search field on top; filters as chips (Dziedzina, Częstotliwość, Źródło, Zasięg); rows show name (link) with domain, sparkline, latest value with period, coverage, sources. The sidebar carries the domains, so the page has no inner domain list. Phone: rows keep name and value only.
