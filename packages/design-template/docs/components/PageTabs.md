Second-level views of one page, each with its own URL.

## Rules
- Links, not ARIA tabs: each view is a page (`aria-current="page"` on the active one).
- Max 5 tabs; labels are nouns (Przegląd, Regiony, Porównanie z UE, Metodologia).
- Active: `ink` weight 600, 2px `accent` underline. Inactive `ink-3`.
- Scrolls horizontally inside itself on phone; 44px high there.
