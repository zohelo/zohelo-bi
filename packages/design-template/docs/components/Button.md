Buttons trigger actions; links navigate.

## Variants
- **Primary** (`accent` fill, `on-inverse` text): the one main action on a page or dialog.
- **Secondary** (surface, `line-strong` border): every other action.
- **Ghost** (accent underlined text): low-weight actions inside a row (Wyczyść).
- **Icon** (36×36, no border): only with an `aria-label`; tooltip on hover.

## Rules
Height `control-h` 36px (44px on phone), `radius-md`, label in sentence case stating the result ("Pobierz dane", not "OK"). One primary per view. Disabled buttons explain why nearby or are not shown.
