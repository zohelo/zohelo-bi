Dashboard-wide filters and comparison chips.

## Rules
- One row under the page header. Each filter is a button showing name and current value; it opens a listbox.
- Filters apply to every card and are written to the URL. A card a filter doesn't apply to says so in its subtitle.
- Comparison chips carry the series colour swatch and a 24px remove button (`aria-label="Usuń <nazwa>"`).
- Toggle chips (`aria-pressed`) for quick on/off filters in the catalogue.
