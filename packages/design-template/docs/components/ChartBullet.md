Wykres pociskowy: wartość wobec celu lub progu, kilka miar obok siebie.

Group: Odchylenie. Example: "Wszystkie miary inflacji blisko celu" (Wartość wobec pasma celu NBP, %, wrzesień 2026).

## When to use
Wartość wobec celu lub progu, kilka miar obok siebie.

## Avoid
Okrągłe wskaźniki „zegarowe”: zajmują miejsce, trudno je porównać.

## Colour and marks
Track `surface-muted`, target range `band`, value bar `series-1`, target tick `ink`; value at the row end.

## Always
Title states the finding; subtitle states measure, unit, frequency and range; `role="img"` with a one-sentence `aria-label`; Wykres | Tabela toggle; source line; phone variant drawn for 340px with 11px text. Draw with `kit/zchart.js` as the visual reference; production charts come from `packages/visuals`.
