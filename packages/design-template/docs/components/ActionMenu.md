The ⋯ menu on every chart card with view, export and context actions.

## Rules
- Trigger: icon button `aria-label="Więcej akcji"`, `aria-expanded`; menu `role="menu"` with `role="menuitem"` items, arrow keys move, Esc closes and returns focus.
- Fixed order: view (Pokaż tabelę, Pełny ekran) · export (Pobierz CSV, Pobierz PNG, Kopiuj link, Osadź) · context (Otwórz w Eksploratorze, Źródło i metodologia).
- `radius-lg`, `shadow-menu`, items 34px.
