# Portals

How each product uses the template.

| | bi.zohelo.com | data.zohelo.com | zohelo.com |
| --- | --- | --- | --- |
| Shell | App shell, every section | App shell for datasets, docs and API; landing page shell open | Site shell (no sidebar) |
| Lockup | `zohelo-bi` | `zohelo-data` | `zohelo` |
| Sidebar groups | Przegląd, Eksplorator, Katalog · Dziedziny · Moje | Zbiory danych by domain · Źródła · API i pobieranie · Dokumentacja | — |
| Page types | Dashboard, Indicator, Explorer, Catalogue | Dataset, Documentation, Catalogue | Landing, Article, Documentation |
| Charts | Full chart library | Previews only (sparkline, small line, table) | Small chart cards, KPI tiles |
| Footer | Thin app footer | Thin app footer | Full footer on `surface-inverse` |

## Shared in every portal

Tokens, fonts, header behaviour (logo left, search, PL | EN), focus and keyboard rules, status tags, sample-data badge, chart rules, footer source line, the definition of done.
